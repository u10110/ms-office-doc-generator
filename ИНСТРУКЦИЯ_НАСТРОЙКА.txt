ГЕНЕРАТОР ДОКУМЕНТОВ (Excel + Word, без установки программ)
==============================================================

ЧТО НУЖНО: Microsoft Excel и Microsoft Word (уже установлены).
НИЧЕГО устанавливать НЕ НУЖНО.

ШАБЛОНЫ
---------
1. Рядом с этим файлом создайте папку "Шаблоны".
2. Внутри "Шаблоны" создайте подпапки — каждая подпапка = один вид договора/пакета.
   Например:
       Шаблоны\Договор_купли_продажи\
       Шаблоны\Договор_аренды\
3. В каждую подпапку положите файлы .docx (шаблоны Word).
4. В шаблонах плейсхолдеры (места для вставки значений) выделите ЖЁЛТЫМ ЦВЕТОМ
   (Главная -> Маркер выделения текста -> Жёлтый).
   Например, выделите жёлтым: Договор № ____ от ____ г.
   Текст внутри жёлтого выделения станет названием колонки в реестре.
   Один и тот же жёлтый текст на разных шаблонах — одна колонка.

СОЗДАНИЕ РЕЕСТРА ОДИН РАЗ
--------------------------
1. Создайте новую пустую книгу Excel.
2. Сохраните её как "Реестр.xlsm" (тип "Книга Excel с поддержкой макросов")
   в ту же папку, где лежит папка "Шаблоны".
3. Нажмите Alt+F11 (откроется редактор Visual Basic).
4. В меню: Файл -> Импортировать файл... -> выберите файл "Макросы.bas".
5. Слева в дереве найдите "ЭтаКнига" (ThisWorkbook), дважды щёлкните.
6. В открывшееся окно вставьте код:

      Private Sub Workbook_Open()
          Application.ScreenUpdating = False
          Call ScanTemplates
          Application.ScreenUpdating = True
      End Sub

7. Нажмите Ctrl+S, закройте редактор.
8. Сохраните и закройте Реестр.xlsm.

КНОПКИ ДЛЯ УДОБСТВА (опционально)
----------------------------------
1. Откройте Реестр.xlsm.
2. На первом листе (можно создать новый и назвать "Меню"):
   Вкладка "Разработчик" -> "Вставить" -> "Кнопка (элемент управления формы)".
   Нарисуйте кнопку, назначьте ей макрос "ScanTemplates" (подпись: "Обновить реестр из шаблонов").
   Сделайте вторую кнопку с макросом "GenerateDocuments" (подпись: "Сгенерировать документы").
   Если вкладки "Разработчик" нет: Файл -> Параметры -> Настроить ленту -> поставьте галочку "Разработчик".

КАК РАБОТАТЬ
------------
1. Добавьте/измените шаблоны в папке "Шаблоны".
2. Откройте Реестр.xlsm.
   При открытии Excel сам просканирует все шаблоны, найдёт жёлтые плейсхолдеры
   и создаст/обновит листы-реестры (один лист на каждую подпапку).
3. Колонки в листе = жёлтые плейсхолдеры из шаблонов.
4. Заполните строки: каждая строка = один пакет документов.
5. Нажмите кнопку "Сгенерировать документы" (или запустите макрос GenerateDocuments).
6. Готовые документы появятся в папке "Выход\<имя_листа>\Строка_NNN\".

СТРУКТУРА ВЫХОДА
----------------
Выход\
   Договор_купли_продажи\
      Строка_002\
         Договор.docx
         Акт.docx
      Строка_003\
         Договор.docx
         Акт.docx
   Договор_аренды\
      Строка_002\
         Договор.docx
         Счёт.docx

Каждая папка "Строка_NNN" содержит полный набор файлов из соответствующей
папки шаблонов, где жёлтые плейсхолдеры заменены значениями из реестра.

ВАЖНО
-----
- Не меняйте вручную заголовки в первой строке листа — они пересоздаются
  автоматически при открытии файла из шаблонов.
- Все данные, введённые в строки 2+, сохраняются.
- Если плейсхолдер из шаблона отсутствует в реестре (пустая ячейка), он будет
  заменён на пустую строку.
- Если в папке шаблонов несколько .docx, все они генерируются для каждой строки.
