# Task

Для реализации вашей задачи в экосистеме Microsoft Office есть два принципиально разных пути: классический (макросы VBA) и современный (надстройки на JS / Power Automate). Так как вы упомянули частые изменения в верстке документов, лучшим выбором будет решение на базе Power Automate + Слияние (Mail Merge) или Excel VBA, где шаблоны Word остаются обычными файлами, которые вы сможете редактировать сами в любой момент.
Ниже представлена предварительная оценка стоимости, сроков и архитектуры решения.

Архитектура решения (Как это будет работать)
Файлы шаблонов с возможными приложениями или вариативностью лижета в папке с реестром.
Единый источник данных: Файл Excel (Реестр сделок). Вы заполняете одну строчку (ФИО/Название, ИНН, Дата, Сумма, Реквизиты).
Генератор (Надстройка): Кнопка в Excel «Сформировать пакет». На основании содержимого генерируется пакет и кладется в новую созданную папку. 
Выходной пакет (в одну папку):
Word: Договор, Заявление, Приложения (Оговорки).
Excel: Табличные приложения (автоматически фильтруются под клиента), Счет на оплату.

Примечание: Финальная стоимость зависит от количества приложений в формате Excel и сложности логики (например, нужно ли скрывать отдельные пункты в договоре в зависимости от условий).

Что требуется от вас (Для старта работы)
Чтобы специалист смог назвать точную цифру и не закладывал риски в бюджет, вам нужно подготовить:
Эталонный пакет документов: Один полностью заполненный вручную реальный кейс (Договор + Заявление + Все приложения + Счет).
Выделение переменных: Желтым маркером в документах выделите всё, что меняется от клиента к клиенту.
Связи: Укажите, откуда берутся данные для таблиц Excel (Приложений) — они статичны или собираются из других систем?





# MS Office Document Generator

Автоматическая генерация пакета документов (Word + Excel) на основе шаблонов и реестра клиентов.

## Структура папок

```
ms-office-doc-generator/
├── README.md                  ← эта инструкция
├── Реестр_клиентов.xlsx       ← реестр с листами для каждого набора
├── Шаблоны/
│   ├── Договор/                ← папка шаблона «Договор»
│   │   ├── 1. Договор.docx     ← шаблон для Набор1
│   │   └── 2. Договор.docx     ← шаблон для Набор2
│   ├── Заявление/               ← папка шаблона «Заявление»
│   │   ├── 1. Заявление.docx
│   │   └── 2. Заявление.docx
│   ├── Прилож3/                 ← папка шаблона «Приложение №3»
│   │   ├── 1. Прилож3.docx
│   │   └── 2. Прилож3.docx
│   ├── Счёт/                    ← папка шаблона «Счёт»
│   │   ├── 1. Счёт.docx
│   │   └── 2. Счёт.docx
│   └── Лист/                    ← папка шаблона «Лист ознакомления»
│       ├── 1. Лист.docx
│       └── 2. Лист.docx
├── Модуль.bas                   ← VBA-модуль для Excel
└── Выход/                        ← готовые пакеты (создаётся автоматически)
    └── ДГ-2025-001/              ← подпапка по номеру договора из реестра
        ├── Договор.docx
        ├── Заявление.docx
        ├── Прилож3.docx
        ├── Счёт.docx
        └── Лист.docx
```

## Принцип работы с несколькими наборами

- Шаблоны организованы по **папкам** (Договор, Заявление, Прилож3, Счёт, Лист)
- Внутри каждой папки — **подпапки по номеру набора** (1, 2, 3...)
- В `Реестр_клиентов.xlsx` для каждого набора — отдельный лист (Набор1, Набор2...)
- При запуске VBA-скрипт автоматически находит все папки в `Шаблоны/` и подхватывает соответствующие листы из реестра
- Готовые пакеты складываются в подпапки `Выход/` по **номеру договора** из колонки "номер договора" в реестре

## Использование

### Подготовка

1. Создайте папку шаблона в `Шаблоны/` (например, `Шаблоны/Договор/`)
2. Скопируйте шаблоны Word (.docx) в подпапки по номеру набора (1, 2, 3...)
3. Откройте `Реестр_клиентов.xlsx`
4. Добавьте лист с именем, совпадающим с названием набора (например, `Набор1`)
5. Заполните лист данными клиентов (каждая строка — один клиент)

### Запуск генерации

1. Откройте `Реестр_клиентов.xlsx`
2. Нажмите кнопку **«Сформировать пакет»** (Alt+F8 → GeneratePackage)
3. Готовые пакеты появятся в папке `Выход/` в подпапках по номеру договора

| `{{ИНН}}` | ИНН |
| `{{КПП}}` | КПП |

| `{{Банк}}` | Банк |
| `{{К/с}}` | К/с |
| `{{БИК}}` | БИК |
| `{{номер ОГРН}}` | ОГРН |
| `{{дата ОГРН}}` | Дата ОГРН |
| `{{территория действия}}` | территория действия |
| `{{срок действия с}}` | срок действия с |
| `{{срок действия по}}` | срок действия по |
| `{{Сумма_1}}` | Сумма_1 |

### Требования

- Microsoft Excel (с поддержкой VBA)
- Microsoft Word (для генерации документов)
- Реестр должен быть в формате `.xlsx`
- Шаблоны Word должны быть в формате `.docx`
