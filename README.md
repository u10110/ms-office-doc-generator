# Генератор пакетов документов (Excel VBA + Word)

Работает полностью внутри Microsoft Excel через VBA-макросы. Не требует Python, не требует установки дополнительных программ. Достаточно Excel и Word.

## Быстрый старт

1. Распакуйте содержимое в рабочую папку.
2. Создайте рядом папку `Шаблоны\`, внутри — подпапки с `.docx` шаблонами.
3. В шаблонах Word выделяйте плейсхолдеры жёлтым цветом.
4. Один раз создайте `Реестр.xlsm` с макросом (см. `ИНСТРУКЦИЯ_НАСТРОЙКА.txt`, 8 шагов).
5. Открывайте `Реестр.xlsm` — он сам построит листы-реестры из шаблонов.
6. Заполните строки и нажмите кнопку **Сгенерировать документы**.

## Структура

```
ms-office-doc-generator/
├── Запустить_реестр.bat       ← открывает Реестр.xlsm
├── Макросы.bas                ← VBA-модуль для импорта в Excel
├── ИНСТРУКЦИЯ_НАСТРОЙКА.txt   ← подробная инструкция (8 шагов)
├── Шаблоны/                   ← создаёте сами
│   └── <Вид_договора>/
│       ├── Договор.docx       ← плейсхолдеры = жёлтый текст
│       └── Акт.docx
└── Выход/                     ← создаётся автоматически
    └── <Вид_договора>/
        └── Строка_NNN/
            └── *.docx
```

## Логика работы

| Шаг | Действие |
|---|---|
| Шаблоны | Пользователь кладёт `.docx` в подпапки `Шаблоны/`. Плейсхолдеры выделены жёлтым |
| Открытие | `Workbook_Open` сканирует шаблоны через Word, извлекает жёлтые тексты |
| Листы | Excel автоматически создаёт/обновляет листы = подпапки. Колонки = уникальные плейсхолдеры |
| Заполнение | Пользователь вводит значения в строки (каждая строка = один пакет документов) |
| Генерация | Макрос `GenerateDocuments` копирует шаблоны, заменяет жёлтый текст на значения из строки |

## Принцип обновления реестра

- При открытии `Реестр.xlsm` макрос перечитывает шаблоны.
- Первая строка листа пересоздаётся полностью (новые колонки справа, старые данные в строках 2+ сохраняются).
- Один и тот же плейсхолдер на разных шаблонах = одна колонка.

## Замена

- Макросы используют установленный Microsoft Word через COM.
- Жёлтый выделенный текст в `.docx` заменяется значением из ячейки.
- Выделение снимается (текст становится обычным).
