# MS Office Document Generator

Автоматическая генерация пакета документов (Word + Excel) на основе шаблонов и реестра клиентов.

## Структура папок

```
ms-office-doc-generator/
├── README.md                  ← эта инструкция
├── Реестр_клиентов.xlsx       ← таблица с клиентами (с фильтрами)
├── Шаблоны/
│   ├── Набор1/                ← первый набор шаблонов
│   │   ├── 1. Договор.docx
│   │   ├── 2. Заявление.docx
│   │   ├── 3. Прилож3.docx
│   │   ├── 4. Счёт.docx
│   │   └── 5. Лист.docx
│   └── Набор2/                ← второй набор шаблонов (опционально)
│       ├── 1. Договор.docx
│       ├── 2. Заявление.docx
│       ├── 3. Прилож3.docx
│       ├── 4. Счёт.docx
│       └── 5. Лист.docx
├── Модуль.bas                 ← VBA-модуль для Excel
└── Выход/                      ← готовые пакеты (создаётся автоматически)
    └── Иванов И.И./
        ├── Договор.docx
        ├── Заявление.docx
        ├── Прилож3.docx
        ├── Счёт.docx
        └── Лист.docx
```

## Несколько наборов шаблонов

Каждый набор в папке `Шаблоны/` — это отдельная конфигурация документов.

- **Набор1** — базовый пакет (Договор + Заявление + Приложение + Счёт + Лист)
- **Набор2** — расширенный пакет (можно добавить дополнительные документы)
- Можно создавать свои наборы: `Набор3/`, `Набор4/` и т.д.

При генерации VBA-скрипт берёт шаблоны из выбранного набора и создаёт пакет для каждого клиента из реестра.

## Использование

### Подготовка

1. Скопируйте нужный набор шаблонов в папку `Шаблоны/`
2. Откройте `Реестр_клиентов.xlsx` в Excel
3. Заполните реестр данными клиентов (каждая строка — один клиент)

### Запуск генерации

1. Откройте `Реестр_клиентов.xlsx`
2. Нажмите кнопку **«Сформировать пакет»** (Alt+F8 → GeneratePackage)
3. Готовые пакеты появятся в папке `Выход/`

### Переменные в шаблонах

Жёлтые выделения в шаблонах Word заменяются на данные из реестра:

| Переменная | Колонка в реестре |
|------------|-------------------|
| `{{номер договора}}` | номер договора |
| `{{дата договора}}` | дата договора |
| `{{Наименование клиента}}` | Наименование клиента |
| `{{Юрадрес клиента}}` | Юрадрес клиента |
| `{{ИНН}}` | ИНН |
| `{{КПП}}` | КПП |
| `{{Р/с}}` | Р/с |
| `{{Банк}}` | Банк |
| `{{К/с}}` | К/с |
| `{{БИК}}` | БИК |
| `{{номер ОГРН}}` | ОГРН |
| `{{дата ОГРН}}` | Дата ОГРН |
| `{{территория действия}}` | территория действия |
| `{{срок действия с}}` | срок действия с |
| `{{срок действия по}}` | срок действия по |
| `{{Сумма_1}}` | Сумма_1 |
| `{{Сумма_2}}` | Сумма_2 |
| `{{Должность_подписанта_1}}` | Должность_подписанта_1 |
| `{{ФИО_подписанта_1}}` | ФИО_подписанта_1 |
| `{{Должность_подписанта_2}}` | Должность_подписанта_2 |
| `{{ФИО_подписанта_2}}` | ФИО_подписанта_2 |

### Требования

- Microsoft Excel (с поддержкой VBA)
- Microsoft Word (для генерации документов)
- Реестр должен быть в формате `.xlsx`
- Шаблоны Word должны быть в формате `.docx`
