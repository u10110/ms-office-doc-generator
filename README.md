# Генератор пакетов документов

Автоматическая генерация пакетов документов Word на основе реестра Excel. Работает без Microsoft Office — нужен только Python (входит в Windows 10/11).

## Быстрый старт

1. Распакуйте архив в любую папку.
2. Дважды кликните **start.bat** (или откройте терминал и выполните `python generate.py`).
3. Готовые пакеты появятся в папке **Выход/**, в подпапках по номеру договора.

## Принцип работы

- **Листы реестра** → каждый лист = один набор (Набор1, Набор2…).
- **Папки шаблонов** → в каждой папке шаблонов лежат файлы `1. <тип>.docx`, `2. <тип>.docx`, и т.д.
- **Номер договора** → столбец с заголовком `номер договора` (первый столбец создаёт папку).
- Строка 1 в реестре — заголовки, строки 2+ — данные клиентов.

## Переменные в шаблонах

В документах Word заключайте перeменные в фигурные скобки, например:
```
{номер договора}
{дата договора}
{Наименование клиента}
```

Система заменит их автоматически на значения из реестра. Названия в скобках **можно писать сокращённо** — главное, чтобы они совпадали с заголовками столбцов реестра. Регистр не важен.

Дополнительно доступны производные поля:
- `ФИО_подписанта_1_инициалы` — инициалы из `ФИО_подписанта_1`
- `ФИО_подписанта_2_инициалы` — инициалы из `ФИО_подписанта_2`

## Зависимости

- Windows 7+ / macOS / Linux
- **Python 3.7+** (на Windows 10/11 обычно уже установлен; если нет — скачайте с python.org)

PyInstaller-сборка не требуется: работает как скрипт.

## Альтернатива: VBA

Если предпочитаете родной макрос Excel, используйте файл `Модуль.bas`:
1. Откройте `Реестр_клиентов.xlsx` в Excel.
2. Нажмите **Alt+F11** → импортируйте `Модуль.bas`.
3. Запустите `GeneratePackage` через **Alt+F8**.

> **Примечание:** для VBA требуются Excel и Word, а также разрешение макросов.

## Кастомизация

### Добавить новый набор шаблонов
1. Создайте в `Шаблоны/<тип>/` файл `3. <тип>.docx`.
2. В реестре Excel добавьте новый лист с именем `Набор3`.

### Добавить новый тип документа
1. Создайте папку `Шаблоны/НовыйТип/`.
2. Добавьте шаблоны `1. НовыйТип.docx`, `2. НовыйТип.docx`.
3. В `generate.py` в переменной `TEMPLATE_TYPES` допишите `"НовыйТип"`.

## Устранение неполадок

- **«python не найден»** при запуске `start.bat`: установите Python с python.org и отметьте галочку **Add Python to PATH**.
- **Шаблон не найден**: убедитесь, что имя файла точно совпадает с форматом `<номер набора>. <тип>.docx`, например `1. Договор.docx`.
- **Ошибка чтения xlsx**: файл реестра должен быть сохранён в формате `.xlsx` (не `.xls`).
